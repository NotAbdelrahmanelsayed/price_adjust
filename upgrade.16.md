# Proposal to upgrade from 15 to 16

This is a proposal to upgrade a frappe-bench server from version 15 to version 16.

## Proposal considers

It's a straight forward task, we will just consider these cases.

- Consistency between applications
- upgrading all standard applications to version-16
- running patches and migration of the database.
- Getting all the services up and running (mariadb, nginx, redis)

## Estimation

this task estimated to take (1-3) hours.

## **NOTE**

if the server on version 14 not 15 we will add one more hour and the task will take (2-5) hours.
